# AMLabSlicer

[简体中文](README.md) · **English**

[![Visit the project website](https://img.shields.io/badge/Website-amlab.top-2563eb?style=for-the-badge)](https://amlab.top/)

AMLabSlicer is a Windows desktop application for FDM slicing, multi-axis 3D printing research, and toolpath visualization. It is developed by the Additive Manufacturing Lab at Tianjin University of Science and Technology.

- **Prepare** · Import models such as STL and STEP, arrange them on the build plate, configure the printer and slicing settings, and save the workspace as an `.amlab` project.
- **Slice** · Switch between planar FDM slicing and experimental AtomSlicer non-planar slicing, each with its own settings.
- **Preview and devices** · G-code toolpath visualization and Moonraker-based monitoring for Klipper printers are under development. Five-axis output is experimental.
