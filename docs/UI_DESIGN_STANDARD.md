# AMLabSlicer UI 设计标准

版本：1.12
制定日期：2026-10-09  
状态：已确认的设计基准；现有界面需逐步按此规范调整，不代表已经完成实现或运行验收。

## 1. 设计目标与适用范围

采用紧凑、低对比度的卡片布局，支持深色与浅色主题，适用于主窗口、参数面板、模型树、工具栏、菜单和设置窗口。界面应符合工程软件的使用习惯：结构明确、参数易读、操作稳定，减少占用空间的装饰。

本标准是后续新增和修改 UI 的默认依据。保持 WPF/MVVM 架构；视觉修改不改变参数绑定、命令、校验和切片业务行为。确需调整标准时，先同步本文件，再更新共用主题与相关视图。

## 2. 布局与卡片

- 模型列表、参数面板、视图区构成主要区域；参数面板内部按功能分组。
- 一个参数卡片包含完整的“分组标题＋参数内容”。标题与内容使用统一背景，避免将标题做成孤立的大按钮。
- 卡片收起后仅保留标题；展开和收起不改变卡片宽度与左右对齐位置。
- 普通文本标签不单独加背景框。背景框用于功能分组、可编辑输入和选中状态。
- 避免多层卡片嵌套、重复边框和装饰性阴影，通过背景层级、间距和对齐区分区域。
- 面板宽度可调整，视图区优先占用剩余空间；长标签可换行或显示省略号并提供完整提示，不覆盖输入框。

## 3. 尺寸与排版

所有尺寸使用 WPF DIP，不直接照搬参考截图的物理像素。下列高度用于默认字号下的单行控件；多行文本、字体放大和换行内容应允许增长，避免裁切。

| 项目 | 默认值 | 说明 |
|---|---:|---|
| 卡片圆角 | 5 | 面板、卡片外边角 |
| 控件圆角 | 5 | 输入框、按钮、下拉框、菜单、选中项 |
| 连接区域内部圆角 | 0 | 相邻拼接区域避免露出背景缝隙 |
| 卡片标题高度 | 30 | 含标题内边距，不再额外叠加上下留白 |
| 单行输入框、下拉框高度 | 26 | 文本垂直居中 |
| 主要操作按钮高度 | 30 | 如切片操作 |
| 参数行高度 | 32 | 包含输入框及上下留白 |
| 分类导航高度 | 30 | 保持单行，溢出时滚动 |
| 切片配置行高度 | 36 | 内部下拉框高度 26 |
| 折叠指示框尺寸 | 20 × 20 | 图标居中；整行标题可点击 |
| 卡片内边距 | 8 | 标题与内容沿同一左边线排列 |
| 卡片间距 | 8 | 不叠加两侧 Margin 形成 16 |
| 标签与输入框最小间距 | 12 | 窄面板仍保持可辨识的分隔 |
| 边框厚度 | 1 | 弱对比度 |
| 正文字号 | 12 | 参数名称、数值、单位、分类标签 |
| 区域标题字号 | 13 | 如模型、参数等区域标题 |
| 分组标题字重 | SemiBold | 不通过增大高度强调标题 |

主工作区的左右面板与工作区背景使用相同颜色，两套主题保持一致；模型列表、参数区、插件面板和切换栏外层使用直角 0，不再显示独立面板底板。仅中央模型预览区域使用完整圆角 5 划分区域。内部设置卡片、输入框和按钮仍保留圆角 5。区域间留 4 DIP 操作间隙，外围留 4 DIP；分隔条默认透明、悬停高亮并可拖动。侧栏收起后去掉对应分隔间隙。

默认字体 Microsoft YaHei，正文 12 DIP；首选项提供系统字体及 10–20 DIP 字号，同级内容统一字号。输入高度为 max(26, 字号+14)，参数行为 max(32, 字号+18)，卡片标题与主要按钮为 max(30, 字号+16)。字号切换通过动态资源同步更新，避免裁切。单行输入框建议水平内边距 6、垂直内边距 1–2；实际模板应正确传递 Padding 和内容对齐，不靠额外外层框补偿。

数值输入框与文本输入框的宽度按内容需要确定，同类字段保持一致；不要为所有控件强制同一宽度。单位与数值共用一个外框，单位预留独立空间。

## 4. 颜色规范

采用中性深灰与单一蓝色强调色。蓝色用于当前选择、键盘焦点和主要操作，不大面积覆盖普通卡片。

| 用途 | 色值 | 对应主题资源 |
|---|---|---|
| 窗口背景 | `#1E1E1E` | `WindowBackgroundBrush` |
| 面板背景 | `#1E1E1E` | `SurfaceBrush` |
| 卡片背景 | `#2B2B2B` | `SurfaceElevatedBrush` |
| 输入框背景 | `#323232` | `ControlBackgroundBrush` |
| 普通边框 | `#424242` | `SurfaceBorderBrush`、`ControlBorderBrush` |
| 主要文字 | `#E6E6E6` | `PrimaryTextBrush` |
| 次要文字、单位 | `#A6A6A6` | `SecondaryTextBrush` |
| 强调色、焦点边框 | `#2D9BFF` | `AccentBrush`、`ControlFocusBorderBrush` |
| 选中项背景 | `#203B56` | `MutedAccentBrush` |

标题栏、工具栏和弹出菜单复用以上背景层级。视图区的背景根据模型辨识度配置，但外围控件遵守同一规范。警告、错误等语义颜色另设专用资源，并配合文字或图标说明，不占用蓝色强调色。

浅色主题复用资源名称：窗口/面板 `#F3F4F6`，卡片/输入 `#FFFFFF`，卡片边框 `#CDD2DA`，输入边框 `#BEC5CE`，正文 `#20252B`，次要文字 `#606975`，强调色 `#0067B8`，选中背景 `#DEECFA`。浅色悬停采用略深中性灰；两套主题保持布局与圆角一致。运行时调色由 `AppearanceService` 统一应用，视图颜色使用 DynamicResource。

## 5. 控件与交互状态

- 默认状态：中性背景、弱边框，普通卡片无明显高亮。
- 悬停状态：使用比默认背景略亮的中性灰；输入框悬停不等同于已获得焦点。
- 键盘焦点：使用蓝色边框或清晰焦点标记，保留 Tab 导航。
- 选中状态：分类导航、模型树等使用淡蓝背景和蓝色文字；模型树已有选中资源应与此保持一致。
- 主要操作：可使用实心蓝色按钮；同一区域避免多个同等强烈的主要操作。
- 禁用状态：降低强调程度，仍保持文字可辨识。
- 输入错误：保留原有校验反馈，不依赖颜色作为唯一提示。
- 分组标题左侧使用竖线标记（视觉形态为“|”），与普通参数和次级内容区分。默认竖线宽 2、高 12，与标题间距 6。
- 折叠操作：整行分组标题（包含竖线、文字、空白和右侧箭头）作为同一个按钮，点击任意位置切换展开/收起；右侧 20 × 20 箭头框只指示状态，不再作为独立按钮。保留键盘聚焦与 Enter/Space 操作，标题悬停时整行轻微高亮。

## 6. 参数面板应用规则

1. 顶部“切片配置”为一条紧凑配置行，总高度 36，标签与下拉框垂直居中。
2. 分类导航保持单行，高度 30，选中项圆角 5、淡蓝背景与蓝色文字。
3. “层高设置”标题、层高与初始层高属于同一卡片；“线宽设置”与线宽参数同样组织。
4. 分组标题左侧添加竖线，标题整行可点击展开/收起，高度 30；参数行默认高度 32；不要在行高外重复增加上下 Margin。
5. 参数名称左对齐，输入框右对齐，数值右对齐；单位在外框内的独立右侧区域显示。无文字复选框的可见方框右边缘与输入框、下拉框右边缘一致，垂直居中；模板不保留空文字间距，行内不增加额外右边距。
6. 所有字段垂直居中，数值和单位只使用一个外边框；外框圆角 5、输入高度 26。
7. 窄面板下优先保留标签与数值输入，辅助滑块可按现有响应规则隐藏；不以裁切数值或单位节省空间。

## 7. 实现约定

- 首选项采用左侧分类、右侧滚动设置卡片、底部保存反馈；可调整窗口大小，最小 640 × 480。
- 首选项“外观与排版”提供中文 / English 语言选择，默认中文，自动保存并即时更新已有界面。语言使用稳定 ID `zh-CN` / `en`；导航分类、主题和命令的内部标识不因翻译而变化。英文文案允许换行，不通过裁切缩短说明。
- 主程序和 Agent 插件共用 WPF SDK 的 `Localization.UiText`、`Text` 和 `LocalizedBinding`，英文词条集中维护于 `AMLabSlicer.Plugin.Wpf/Localization/en.json`。界面标题、标签、按钮及状态在展示层翻译；模型名、聊天内容、配置路径及数值格式不翻译。外部引擎、第三方插件或服务器返回的未知文字保留原文。
- 主窗口最小宽度 960；左侧参数与右侧 Agent 入口在工具栏两端对称。两侧独立展开/收起、可拖动宽度，中间视图区至少保留 300 DIP。
- 左侧下半部参数区最小高度为 150 DIP；上方模型列表的最大高度在布局前按“当前工作区高度减外围上下留白、分隔条和参数区最小高度”计算。拖动横向分隔条或缩小主窗口均不得将参数区挤到可见区域外；内容较多时在参数区内部滚动。
- 模型视图只提供普通模型对象操作。删除选区/分区模式及其入口、工具栏、面片点选/框选/刷选/套索、透视选择、连通选择、面组保存和另存功能；Tab 不再切换模式，保留正常键盘焦点导航。保留普通模型点选、G/R/S 变换、F 底面朝下、A 摆放、B 拆分、X 删除及相机控制。
- Agent 面板默认宽度 360，可设 300–600；展开动画 180 ms，可在“插件 → 插件管理”关闭。头部放新对话和设置，中部滚动消息，底部固定输入与发送/停止操作。
- 首选项提供外观、视图、操作历史、运行与诊断；后者提供“显示 EngineHost 控制台”，默认关闭，保存后下次启动生效，不重启已有服务。Agent 相关设置仅在独立“插件”窗口中编辑，另设插件管理页。Agent 的“设置”和顶部菜单打开 Agent 页，右侧“＋”打开管理页。首选项恢复默认不清除 Agent 配置。
- 最右侧切换栏宽 32，与相邻面板间隙 4，切换栏与对话区一起包含在右侧可折叠面板中，统一展开、收起及拖动宽度；面板宽度包含切换栏与内部间隙。面板条目与内容通过 MVVM 集合切换；Agent 为首个独立 DLL 插件，其他插件由插件管理器发现和加载。显示/隐藏按钮只在悬停时高亮，不保留点击后的焦点背景或虚线。
- 对话气泡使用现有卡片与选中背景，不引入大圆角；长文本换行、可选择复制，错误和取消在状态区明确说明。
- Agent 输入框内边距使用 8，与消息卡片统一。TextBox 的 Padding 由文本宿主处理，模板不得再次将 Padding 作为宿主 Margin，避免留白叠加。
- 全部纵向/横向滚动条共用主题 ScrollBar 模板：透明轨道、无两端箭头、12 DIP 操作区域、6 DIP 可见灰色滑块、小圆角 5；滑块最短操作长度 24。悬停与拖动时加深灰色，深浅主题使用不同灰度。保留滑块拖动、轨道翻页、鼠标滚轮与键盘滚动。
- 首选项、信息/警告提示与操作确认窗口共用 `ThemedWindowStyle`：标题栏 36、小圆角 5、主题边框与背景、共享关闭按钮。消息与长设置可换行或滚动，保留确定、取消和 Esc 行为；应用内提示不使用系统 MessageBox。
- 弹窗圆角必须同时约束 WPF 内容和原生窗口区域，不能只画圆角 Border 而留下不透明黑角。`ThemedWindow` 按物理窗口尺寸及 DPI 更新 5 DIP 原生圆角，调整大小或 DPI 后重新计算；最大化时使用直角。保留原生拖动与缩放边界。
- 弹窗模板根层须用主题背景完全填充，避免圆角抗锯齿处的透明像素与黑色原生底板混合；原生区域尺寸不得比实际窗口多出一个像素。
- 视角立方体保持透明面；浅色主题使用深灰文字 `#505660` 和灰色边线 `#6B7280`，深色主题使用浅灰文字 `#C1C7D0` 和边线 `#A6AFBD`。XYZ 轴保留原有语义颜色；悬停热区仍可短暂高亮。
- Helix 平台格线通过主题颜色资源设置：浅色小格线 `#BFC5CE`、大格线 `#A0A8B4`，大格稍深；深色沿用小格线 `#4D4D4D`、大格线 `#666666`。线宽及网格间距保持原值，切换主题即时更新。
- 侧栏限制在布局 Measure/Arrange 前按父布局提供的可用宽度检查；不能使用已经被内容撑大的内部 Grid.ActualWidth。两侧共享“总宽度减外围左右留白 8、减中央 300、减可见分隔线”的预算，窗口缩小时按各自超过最小宽度的部分成比例收窄，同时更新实际 Width、MinWidth、MaxWidth；收起的侧栏保持零宽。

- 颜色、圆角、通用高度与间距集中定义在 `AMLabSlicer/Themes/DarkTheme.xaml`，通过共用资源与样式引用，避免各视图重复写固定值。
- 保留现有颜色资源名称，统一调整资源值；新增尺寸资源可采用 `UiCornerRadius`、`UiInputHeight`、`UiParameterRowHeight`、`UiCardHeaderHeight`、`UiSpacing` 等语义名称。
- 类型应与 WPF 属性匹配：圆角使用 `CornerRadius`，内外边距使用 `Thickness`，高度使用数值资源。
- `RowDefinition.Height`、`ColumnDefinition.Width` 必须使用 `GridLength` 资源；不能直接引用 `Double` 动态资源。工具栏行定义使用 `UiConfigRowGridHeight`，普通控件高度仍使用 `UiConfigRowHeight`，两者由外观服务同步更新。
- 通用控件模板负责圆角、内容对齐和状态；局部视图负责布局和必要的宽度，不自行覆盖统一颜色和圆角。
- 修改现有样式时保留用户未提交改动；按区域逐步迁移，不通过全局文本替换改变图标、滑块等具有独立几何含义的圆角。

## 8. 验收要求

- 卡片、输入框、按钮和选中项圆角一致，标题与内容形成完整分组。
- 默认字号下单行输入为 26、参数行为 32，文字、数值和单位垂直居中，无多余高度。
- 检查默认、悬停、焦点、选中、禁用及输入错误状态。
- 检查窗口最小尺寸、侧栏收窄、长名称，以及 100%、125%、150% 系统缩放，确保无裁切、重叠和无法访问的操作。
- 验证原有参数编辑、展开收起、分类切换、模型选择与命令绑定正常。
- 对实际 XAML 改动完成受影响 UI 构建及可用的界面检查。构建通过只证明编译结果，截图或实际交互检查才可证明对应的视觉与操作表现。

## 9. 参考边界

本规范参考用户提供的当前参数面板与 Codex 列表截图：采用紧凑文字留白、低对比度背景和小圆角。参考截图用于确定视觉比例，不作为精确像素测量依据。

本文件定义设计与验收依据；具体实现与验证范围记录在 `docs/ui-preview/README.md`，不以规范本身代替运行验收。

- 交互插件只返回 UserControl，由宿主放入右侧面板；禁止插件另开窗口。插件配置编辑仅出现在“插件”窗口所属设置页。右侧 Agent 的模型连接改为只读摘要，模型列表读取与模型选择移到插件设置页。详见 [插件开发标准](PLUGIN_DEVELOPMENT_STANDARD.md)。
