# AMLabSlicer

**简体中文** · [English](README.en.md)

[![访问项目官网](https://img.shields.io/badge/%E5%AE%98%E7%BD%91-amlab.top-2563eb?style=for-the-badge)](https://amlab.top/)

AMLabSlicer 是天津科技大学增材制造实验室开发的 Windows 桌面软件，用于 FDM 切片、多轴 3D 打印研究和轨迹可视化。

- **准备** · 导入 STL、STEP 等模型，调整摆放，配置打印机与切片参数，并将工作区保存为 `.amlab` 工程。
- **切片** · 接入 FDM 平面切片和实验性的 AtomSlicer 非平面切片，参数随所选算法切换。
- **预览与设备** · 正在完善 G-code 轨迹查看和基于 Moonraker 的 Klipper 设备监控。五轴输出仍处于实验阶段。
